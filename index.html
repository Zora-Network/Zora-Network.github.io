What is Zora Network?

Zora is an Ethereum Layer 2 for onchain media and creator markets; the official Zora Network docs describe it as fast, cost-efficient and built to bring media onchain.

How Zora Network works

  1. Open ZoraUse the official app at zora.co, then connect a wallet only after verifying the domain.
  2. Choose the chainSwitch to Zora mainnet in your wallet; the network uses chain ID 7777777 and ETH for gas.
  3. Fund activityBridge ETH only if needed through the official native bridge or another supported bridge, starting with a small test amount.
  4. Explore and verifyCreate, collect or trade in the app, then review transactions on explorer.zora.energy.

Zora Network FAQ

What is zora network?

Zora Network is an Ethereum Layer 2 built with the OP Stack for onchain media, NFTs and creator applications; see the official docs.

Is zora network an Ethereum Layer 2?

Yes. Official network docs list it as an L2 built on Ethereum with the OP Stack, and it uses ETH as the mainnet gas token.

What is the zora network chain ID?

Mainnet chain ID is 7777777; Zora Sepolia testnet is 999999999. Confirm in the network details before signing.

Where is the official zora network app?

Open the official app at zora.co and verify the domain before connecting a wallet.

How do I bridge to zora network?

The official native bridge is bridge.zora.energy; bridge a small test amount first and do not send WETH or unsupported ERC-20s to the bridge address.
